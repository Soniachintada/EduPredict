# EduPredict — Student Performance Predictor

A beginner-friendly full-stack AIML mini-project. It uses a **Random Forest Regression** model to estimate a student's score from four learning indicators and displays the result in a responsive web interface.

> **Academic/demo disclaimer:** The model is trained on synthetic demonstration data generated by the project. It is an end-to-end prototype, not a validated educational assessment tool. Do not use its predictions to make real decisions about students.

## Features

- Responsive frontend with a student input form and prediction dashboard.
- Python FastAPI backend with REST endpoints.
- Scikit-learn Random Forest regression model.
- Estimated score, performance band, risk indicator, and study suggestions.
- API health and model-information endpoints.
- Separate My Task Journey with horizontally scrolling task map and SQLite persistence.
- User-defined task categories, deadlines, status tracking, and in-page browser reminders.
- No paid API required.

## Run locally (Windows)

1. Install Python 3.10 or later.
2. Extract this folder and open it in VS Code.
3. Open the VS Code terminal in the project root.
4. Create and activate a virtual environment:

   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt and run:

   ```bat
   .venv\Scripts\activate.bat
   ```

5. Install the packages:

   ```bash
   pip install -r requirements.txt
   ```

6. Start the backend and frontend together:

   ```bash
   uvicorn backend.main:app --reload
   ```

7. Open **http://127.0.0.1:8000** in your browser.

The interactive API documentation is available at **http://127.0.0.1:8000/docs**.

## My Task Journey

Open **My Task Journey** from the left sidebar to add tasks to a horizontal, Candy Crush-inspired path. Task records are stored in `edupredict_tasks.db` (created automatically). Categories are selected by the user: Immediate, Short-term, Medium-term, or Long-term. Complete, skip, or pause tasks; skipped tasks are not counted as completed. Browser notifications are best-effort reminders while the page is open and notification permission is granted; this prototype does not send push notifications while the browser is closed.

## API endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/api/health` | Check whether the API is running |
| GET | `/api/model-info` | View model algorithm and demo training metrics |
| POST | `/api/predict` | Generate a student performance estimate |
| GET/POST | `/api/tasks` | List and create journey tasks |
| PATCH | `/api/tasks/{id}` | Edit a task |
| PATCH | `/api/tasks/{id}/status` | Update task status |
| DELETE | `/api/tasks/{id}` | Delete a task |


## Machine-learning workflow

1. Generate a reproducible synthetic dataset for demonstration.
2. Split the records into training and test sets.
3. Train a Random Forest Regressor with Scikit-learn.
4. Evaluate the demo model with Mean Absolute Error and R².
5. Use the trained model to estimate a score for the submitted inputs.
6. Convert the estimate into a simple performance band and show general study suggestions.

The reported test metrics describe performance on the synthetic demo data only. For a real deployment, replace the generated data with an authorised, representative, anonymised dataset and evaluate the model with educators before use.

## Suggested presentation explanation

**Problem:** Teachers may find it difficult to identify students who could benefit from extra academic support early.

**Solution:** EduPredict demonstrates how machine learning can analyse study hours, attendance, a previous score, and assignment completion to estimate performance and show supportive suggestions.

**Limitation:** The current project is a prototype trained on synthetic data. Its scores are illustrative and must not be presented as validated predictions for real students.
